# ghwnsehd.github.io

Jekyll 개인 블로그입니다. [Plainwhite Jekyll 테마](https://github.com/samarsault/plainwhite-jekyll)를 사용합니다.

## 로컬에서 실행하기

Ruby와 Bundler를 설치한 뒤 저장소 루트에서 실행합니다.

```sh
bundle install
bundle exec jekyll serve
```

브라우저에서 `http://localhost:4000`을 열어 확인할 수 있습니다.

## 설정

사이트 제목, 소개, 언어, 테마 표시 이름과 GitHub 링크는 `_config.yml`에서 수정합니다. 프로필 사진을 추가하려면 `assets/portfolio.png`를 넣고 `plainwhite.portfolio_image` 설정을 지정하세요.

테마 원본의 MIT 라이선스와 저작권 표시는 [LICENSE.txt](./LICENSE.txt)에 있습니다.
